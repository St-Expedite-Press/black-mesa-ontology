# Reference data

This directory instantiates Black Mesa schema concepts without expanding the core ontology into a crop, pathogen, sensor, or jurisdiction inventory.

Current pilot host/pathogen profiles live in `pilot-pathosystems.ttl`.

Read [pilot pathosystem governance](../docs/governance/pathosystems.md) and [adding a pathosystem](../docs/examples/add-a-pathosystem.md) before adding deployment profiles.
