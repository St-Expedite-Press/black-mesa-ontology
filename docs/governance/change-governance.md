## Required review questions

For each change, identify authoritative source or implementation evidence,
intended scope, whether it changes a term or constraint, fixtures that exercise
it, generated references affected, and unresolved interoperability or security
consequences. Do not promote a source proposal to implemented behavior without
corresponding schema and tests.

Formal approval roles and release authority are not encoded in this repository.
