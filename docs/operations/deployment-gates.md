# Deployment gates

Ontology implementation and production readiness are different questions.

| Capability / dependency | Status |
|---|---|
| core evidence-chain schema | **IMPLEMENTED** |
| SHACL safety constraints | **IMPLEMENTED** |
| four pilot pathosystem profiles | **REFERENCE DATA PRESENT** |
| five state rule intake records | **DRAFT / REVIEW REQUIRED** |
| public W3ID dereferenceability | **EXTERNAL DEPENDENCY / UNVERIFIED** |
| production sensor/model profiles | **PLANNED / DEPLOYMENT-SPECIFIC** |
| validated diagnostic-method profiles | **PLANNED / DEPLOYMENT-SPECIFIC** |
| verified state/pest-specific triggers/deadlines | **DRAFT / REVIEW REQUIRED** |
| environmental-context module | **PLANNED** |
| spread/neighborhood inference | **PLANNED** |
| operational integration/security assurance | **EXTERNAL TO ONTOLOGY** |

A feature represented in OWL is not automatically deployed. A shape that checks a field is not proof that a field workflow is legally sufficient. A draft regulatory record is not operative authority.

Update this page only when repository evidence supports the status change.
