## Checked-in configuration

The schema fixes local namespaces, term definitions, SHACL shapes, and local
import resolution in `tools/validate_ontology.py`. The publication project key
is `black-mesa-ontology`.

No endpoint, credential, object store, database, device, alerting service, or
production model configuration is committed. Do not infer their existence from
conceptual terms.
