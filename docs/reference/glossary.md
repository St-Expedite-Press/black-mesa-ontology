## Glossary

| Term | Plain-language meaning |
|---|---|
| Assay | Analysis performed on one specimen that produces one result |
| Custody chain | Ordered process history behind a detection |
| Detection | Assertion of pathogen presence at a zone and time |
| Imagery reference | URI and checksum pointer to imagery outside RDF |
| Pre-symptomatic indication | Hypothesis from sensed evidence that warrants sampling |
| Spectral anomaly | Data-derived pattern, not a diagnosis |

For authoritative labels and RDF comments, use the generated reference.
