## Conceptual path

The schema can represent an indication from sensed imagery, collection and
analysis of a specimen, and a traceable assertion. It is a model of records and
relationships, not a biological model of infection, transmission, crop stress,
or causal inference.

The project provides no empirical dataset, benchmark, sensitivity estimate,
specificity estimate, field trial, or pathogen prevalence result. No such claim
should be inferred from valid RDF or SHACL conformance.
