## No inference engine

No classifier, rule engine, assay chemistry implementation, or identification
algorithm is committed here. The schema can record which rule-set version
generated a detection and can represent a confidence assessment. It does not
say how to derive a detection from imagery or a result.

Anomaly evidence can justify a sampling request. It must not be described as
identification, confirmation, threat assessment, or a prediction of intent.
