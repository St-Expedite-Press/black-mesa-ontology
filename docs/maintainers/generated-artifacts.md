## Generated references

`docs/reference/schema-reference.md` and `docs/reference/class-diagram.md`
are generated from `schema/*.ttl` by `tools/schema_docs.py`. Their headers
name the source and regeneration command. Regenerate with:

```powershell
python tools/schema_docs.py --schema projects/black-mesa-ontology/schema --out projects/black-mesa-ontology/docs/reference
```

The flattened layout changes only paths: `--schema schema --out docs/reference`.
Generated bytes are compared with committed output in a temporary directory by
the documentation test. Do not hand-edit generated files.
