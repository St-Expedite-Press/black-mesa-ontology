## Checklist

- [ ] Review schema and SHACL changes against authoritative evidence.
- [ ] Regenerate `docs/reference/` and confirm the freshness test.
- [ ] Run strict lint for authored active documents.
- [ ] Run documentation, ontology, and complete test checks in canonical layout.
- [ ] Assemble a disposable flattened repository and repeat its checks.
- [ ] Review for internal material, private identifiers, credentials, and unsupported claims.
- [ ] Confirm license and third-party notices are adequate.
- [ ] Obtain publication authorization before pushing or publishing.

This repository has no committed reuse license, so the license item cannot be
marked complete without a separate decision.
