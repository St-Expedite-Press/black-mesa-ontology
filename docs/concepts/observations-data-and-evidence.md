## Evidence boundary

A spectral anomaly is a record of a pattern found in imagery. It may warrant
sampling but does not itself assert disease or pathogen presence. An imagery
reference points to bytes held outside the graph using a URI and checksum.

The checked-in shape requires an anomaly to reference imagery, but it does not
verify that the URI resolves, the checksum matches data, or a model was
calibrated. Missing data is not evidence of absence or safety.
