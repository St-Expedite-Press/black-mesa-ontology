## Key distinctions

| Term | Meaning in this project | Not equivalent to |
|---|---|---|
| Spectral anomaly | Data-derived pattern localized to a zone | Crop disease or diagnosis |
| Detection | Provenanced assertion about pathogen presence | Field property or alert |
| Assay result | Datum produced by an assay | Detection assertion |
| Pre-symptomatic indication | Hypothesis that warrants sampling | Suspected diagnosis |
| Not detected | Assay ran and returned negative | No observation made |
| Alert | Separate directive based on a detection | Detection itself |

Use the generated reference for formal labels and comments.
