## Reuse

The core reuses BFO through the shared upper module and references selected
external vocabulary terms. NCBITaxon identifiers are intended as references,
not copied taxonomy content. This supplies integration points but does not
implement cross-system exchange.

## Reporting crosswalks

`ReportingCrosswalk` records a source term and mapping fidelity. No NPDN or
CAP mapping instances are present. The pre-symptomatic indication has no
established external equivalent here; a missing mapping must remain explicit.
