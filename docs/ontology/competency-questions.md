## Questions

- Which zone does a detection concern?
- Which assay result and custody chain support it?
- Which rule-set version generated the assertion?
- Which imagery reference was associated with an anomaly?
- Did a detection trigger an alert?
- Does a crosswalk declare its fidelity?

The SHACL shapes exercise several minimum-information questions. No committed
SPARQL query suite or production dataset exists, so these are modeling targets
rather than demonstrated operational results.
