## Integration discipline

Identify the external contract, version, authorization requirements, data
semantics, and failure behavior. Record each mapping with direction and
fidelity; represent no mapping where that is the honest result. Add fixtures
and tests for an exchange boundary before documenting it as implemented.

No NPDN or CAP integration is implemented or mapped in this repository.
