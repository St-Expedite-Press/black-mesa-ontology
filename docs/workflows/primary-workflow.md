## Workflow

1. Record a flight and any spectral-anomaly record it produces.
2. Link an anomaly to an imagery reference and, if collection occurs, a collection act.
3. Record the specimen, assay, and assay result.
4. Create a detection only with zone, result, custody chain, and rule-set version.
5. Record a separate alert only if a policy process creates one.

The schema does not execute these steps or decide when any of them is warranted.
