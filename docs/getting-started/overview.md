## Scope

The schema represents records around a possible pathogen detection: a flight can
produce spectral-anomaly records; an anomaly can prompt collection; an assay
produces a result; a detection is an assertion derived from results and custody
information; an alert is separate.

It does not establish pathogen presence, automate inference, operate a drone,
store raw imagery, implement NPDN or CAP exchange, or supply a production data
service. See [limitations](../methodology/validation-and-limitations.md).
