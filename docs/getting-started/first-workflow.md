## Record a reviewable chain

Create records for a flight, anomaly, collection, specimen, assay, result,
custody chain, and detection assertion. The detection must identify one zone,
at least one assay result, one custody chain, and the rule-set version under
which it was made. A later alert, if any, is a separate record.

Use [the minimal example](../examples/minimal-example.md) as a synthetic,
shape-oriented illustration. It is not a prescription for an operational workflow.
