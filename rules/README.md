# Jurisdictional rule registry

This directory contains jurisdiction-specific `ReportingRule` records.

Current Arkansas, Louisiana, Missouri, Oklahoma, and Texas records are **draft, non-operative intake records**. They require human review and cannot authorize autonomous external notification.

For semantics, lifecycle, review requirements, and safety policy, read [regulatory-rule governance](../docs/governance/regulatory-rules.md).

Directories use ISO-style jurisdiction labels: `US-AR`, `US-LA`, `US-MO`, `US-OK`, and `US-TX`.
